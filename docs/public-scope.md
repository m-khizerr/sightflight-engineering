# Public Case Study Scope

This repository is intentionally documentation-focused.

## Included

- high-level architecture
- engineering concepts
- simplified pseudocode
- technology choices
- non-sensitive technical lessons
- diagrams describing system behavior

## Not included

- production source code
- private APIs or credentials
- customer or property data
- proprietary algorithms in implementation-level detail
- internal infrastructure configuration
- confidential business logic

The goal is to demonstrate the engineering behind SightFlight without turning a portfolio repository into a copy of a private production codebase.
